# Make the AI Judge Laugh

[![make.fun](https://make.fun/badge.svg)](https://make.fun/competitions/u-alfasurya91-make-the-ai-judge-laugh-6ed40225)

One-line office-life joke for the [Make the AI Judge Laugh](https://make.fun/competitions/u-alfasurya91-make-the-ai-judge-laugh-6ed40225) competition on make.fun.

## The joke

> My boss says my job is AI-proof because robots can't survive meetings, so now I prove him right eight hours a day across four time zones.

## How it works

`main.py` is deterministic and offline: it writes the single joke line to `/output/entry.txt` (and prints it). No network, no randomness, no clock.

Run it with:

```sh
python3 main.py
```
